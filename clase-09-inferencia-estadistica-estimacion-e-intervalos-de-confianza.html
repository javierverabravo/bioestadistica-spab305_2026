Programa oficial UNAB · Inferencia

Inferencia estadística

A partir de una muestra, extendemos los resultados a la población de interés. Nunca observamos toda la población: trabajamos con una parte y cuantificamos la incertidumbre.

Parámetro y estadístico

El parámetro describe la población (μ, σ, π); el estadístico se calcula en la muestra (x̄, s, p) y estima al parámetro.

Programa oficial UNAB · Estimación

Estimación puntual y sus propiedades

Estimación puntualUn único valor (por ejemplo, x̄) como mejor aproximación del parámetro.
InsesgadoEn promedio, acierta el valor del parámetro (sin sesgo sistemático).
Varianza mínimaEntre los insesgados, el que menos varía de muestra a muestra.

Un buen estimador es insesgado y preciso; la media muestral cumple ambas propiedades bajo condiciones amplias.

Programa oficial UNAB · Intervalos de confianza

Intervalo de confianza para una media

En vez de un solo número, damos un rango que probablemente contiene el parámetro, con un nivel de confianza fijado.

x̄ ± Z · (σ/√n)

Z = 1,96 para el 95 % · Z = 2,576 para el 99 %.

Ejercicio resuelto · Clase 9

Intervalo de confianza para una media con σ conocida

Dificultad media
Una epidemióloga mide la glicemia de una muestra aleatoria de 100 pacientes diabéticos y obtiene una media de 170 mg/dL. Por estudios previos se sabe que la desviación estándar poblacional es 10 mg/dL. Construya el intervalo de confianza al 95 % e interprételo correctamente.
  1. Identificar los datos y comprobar que se puede usar la distribución normal: σ es conocida y n es grande.
    n = 100 · X̄ = 170 · σ = 10
  2. Calcular el error estándar de la media, que es la desviación estándar de la distribución muestral.
    EE = σ / √n = 10 / 10 = 1,0 mg/dL
  3. Buscar el valor crítico para el 95 % de confianza, que deja 2,5 % en cada cola.
    Z₀,₀₂₅ = 1,96
  4. Calcular el margen de error, que es el valor crítico por el error estándar.
    d = 1,96 × 1,0 = 1,96 mg/dL
  5. Construir el intervalo restando y sumando el margen a la estimación puntual.
    IC₉₅ = 170 ± 1,96 → [168,04 ; 171,96] mg/dL
  6. Enunciar la interpretación correcta, que se refiere al procedimiento y no a este intervalo en particular.
    «Si repitiéramos el estudio muchas veces, el 95 % de los intervalos así construidos contendría la media poblacional.»
  7. Descartar explícitamente la interpretación incorrecta más frecuente.
    Es incorrecto decir «hay 95 % de probabilidad de que μ esté entre 168,04 y 171,96». μ es un valor fijo: o está o no está.
  8. Comprobar el efecto del tamaño muestral recalculando con n = 400.
    EE = 10/20 = 0,5 → IC₉₅ = [169,02 ; 170,98], la mitad de ancho
IC₉₅ = [168,04 ; 171,96] mg/dL. Cuadruplicar la muestra reduce el ancho del intervalo a la mitad, porque el error estándar depende de √n.
Cómo se vería la representación

Cuadruplicar la muestra reduce el ancho a la mitad: el error estándar depende de la raíz de n.

Intervalo de confianza para una media

Recurso opcional. Este script no se dicta en cátedra. Está aquí para quien quiera comprobar el desarrollo por su cuenta: cópialo, pégalo en RStudio y verifica cada paso. La idea es que te familiarices con cómo se resuelve con software un problema de este tipo. El desarrollo usa solo R base, incluye cómo obtener la representación gráfica, y el atajo del final usa la función que lo resuelve directo.

# =====================================================================
# Clase 9 - Intervalo de confianza para una media con sigma conocida
# =====================================================================
n <- 100; xbar <- 170; sigma <- 10      # glicemia, mg/dL

# Paso 1 y 2. Error estandar: la desviacion de la MEDIA muestral
EE <- sigma / sqrt(n); EE                 # 1,0 mg/dL

# Paso 3. Valor critico del 95 %: deja 2,5 % en cada cola
z <- qnorm(0.975); z                      # 1,96

# Paso 4 y 5. Margen de error e intervalo
d <- z * EE; d                            # 1,96
IC <- xbar + c(-1, 1) * d; IC             # 168,04 a 171,96

# Paso 6. Interpretacion CORRECTA: se refiere al procedimiento.
# Si repitieramos el estudio muchas veces, el 95 % de los intervalos
# asi construidos contendria la media poblacional.

# Paso 7. Interpretacion INCORRECTA: "hay 95 % de probabilidad de que
# mu este entre 168,04 y 171,96". mu es fijo: o esta o no esta.

# Paso 8. Efecto del tamano muestral
sigma/sqrt(400)                           # el EE se reduce a la mitad
xbar + c(-1,1) * qnorm(.975) * sigma/sqrt(400)
# Cuadruplicar n reduce el ancho a la mitad: depende de sqrt(n)

# ---------------------------------------------------------------------
# Atajo: comprobar por simulacion que el 95 % es del PROCEDIMIENTO
# ---------------------------------------------------------------------
set.seed(1); mu_real <- 170
cubre <- replicate(10000, {
  m <- mean(rnorm(n, mu_real, sigma))
  ic <- m + c(-1,1) * qnorm(.975) * sigma/sqrt(n)
  ic[1] <= mu_real & mu_real <= ic[2]
})
mean(cubre)                               # cercano a 0,95

# ---------------------------------------------------------------------
# Representacion grafica: 100 intervalos, unos pocos fallan
# ---------------------------------------------------------------------
set.seed(7)
ics <- t(replicate(100, { m <- mean(rnorm(n, mu_real, sigma))
                          m + c(-1,1) * qnorm(.975) * sigma/sqrt(n) }))
falla <- ics[,1] > mu_real | ics[,2] < mu_real
plot(NULL, xlim = range(ics), ylim = c(0,101), yaxt = "n", ylab = "",
     xlab = "glicemia media (mg/dL)",
     main = paste0("100 intervalos del 95 %: fallan ", sum(falla)))
segments(ics[,1], 1:100, ics[,2], 1:100, col = ifelse(falla, "firebrick", "grey70"), lwd = 2)
abline(v = mu_real, lwd = 2)
# El parametro esta quieto; lo que se mueve son los intervalos.
Pregunta de discusión · qué significa la confianza

Qué se repite en el 95 %

Un estudio informa que la presión sistólica media es de 132 mmHg, con un intervalo de confianza del 95 % entre 128 y 136. ¿Cuál de estas afirmaciones es correcta?

AQue hay un 95 % de probabilidad de que la media de toda la población esté entre 128 y 136.
BQue al repetir muchas veces el estudio, el 95 % de esos intervalos contendría la media.
CQue el 95 % de los pacientes del estudio tiene su presión entre 128 y 136 mmHg.
DQue hay un 95 % de probabilidad de que la media de otra muestra caiga en ese rango.

La confianza es una propiedad del procedimiento, no de este intervalo en particular: la media poblacional es un número fijo, y este intervalo la contiene o no la contiene. Leerlo como el rango donde cae el 95 % de los pacientes confunde el intervalo de confianza con la dispersión de los datos, error frecuente y de consecuencia clínica directa.

Programa oficial UNAB · Intervalos de confianza

¿Qué significa "95 % de confianza"?

No es que haya un 95 % de probabilidad de que este intervalo contenga el valor. Es que, si repitiéramos el estudio muchas veces, el 95 % de los intervalos construidos así contendría el parámetro.

Aproximadamente 1 de cada 20 intervalos del 95 % no contiene el valor real, y no sabemos cuál.

Programa oficial UNAB · Intervalos de confianza

Cuando no conocemos σ: la t de Student

Con muestras pequeñas y σ desconocido, se usa la desviación muestral s y la distribución t de Student, que tiene colas más pesadas para reflejar esa incertidumbre extra.

x̄ ± t · (s/√n)

Con n grande (≥ 30), la t se acerca a la normal.

Ejercicio resuelto · Clase 9

Tres intervalos sobre los mismos datos

Dificultad alta
Se aplica una escala de depresión a 45 personas y se obtiene media 22,4 puntos y desviación estándar muestral 6,8 puntos. Construya: (a) el IC 95 % suponiendo σ conocida e igual a 6,8; (b) el IC 95 % con σ desconocida; (c) el IC 99 % con σ desconocida. Compare los tres.
  1. Calcular el error estándar, que es el mismo en los tres casos porque solo depende de la dispersión y de n.
    EE = 6,8 / √45 = 6,8 / 6,708 = 1,014 puntos
  2. Para (a), con σ conocida el valor crítico proviene de la normal estándar.
    Z₀,₀₂₅ = 1,96 → d = 1,96 × 1,014 = 1,99
  3. Construir el primer intervalo.
    IC₉₅(Z) = 22,4 ± 1,99 → [20,41 ; 24,39]
  4. Para (b), con σ desconocida el valor crítico proviene de la t de Student, con n − 1 grados de libertad.
    gl = 45 − 1 = 44 → t₀,₀₂₅ ; ₄₄ = 2,015
  5. Construir el segundo intervalo.
    d = 2,015 × 1,014 = 2,04 → IC₉₅(t) = [20,36 ; 24,44]
  6. Para (c), subir el nivel de confianza al 99 % obliga a alejarse más en las colas.
    t₀,₀₀₅ ; ₄₄ = 2,692 → d = 2,692 × 1,014 = 2,73
  7. Construir el tercer intervalo.
    IC₉₉(t) = 22,4 ± 2,73 → [19,67 ; 25,13]
  8. Comparar (a) y (b): la t es apenas más ancha que la Z porque con 44 grados de libertad ambas distribuciones casi coinciden. Con n pequeño la diferencia sería grande.
    Ancho: 3,98 frente a 4,08 puntos
  9. Comparar (b) y (c) y enunciar el intercambio de fondo: más confianza se paga con menos precisión. Un IC del 100 % sería el rango completo de la escala y no diría nada.
    Ancho: 4,08 frente a 5,46 puntos
(a) [20,41 ; 24,39] · (b) [20,36 ; 24,44] · (c) [19,67 ; 25,13]. Con n = 45 la t y la Z son casi equivalentes; subir la confianza al 99 % ensancha el intervalo un 34 %.
Cómo se vería la representación

Con 44 grados de libertad, t y z casi coinciden. Subir al 99 % ensancha el intervalo un 34 %.

Regla práctica: con σ desconocida se usa siempre la t. Con n grande la t converge a la Z, de modo que usar la t nunca es un error.

# Clase 9 - Tres intervalos sobre los mismos datos
# =====================================================================
n <- 45; xbar <- 22.4; s <- 6.8       # escala de depresion

# Paso 1. Error estandar: el mismo en los tres casos
EE <- s / sqrt(n); EE                   # 1,014

# Paso 2 y 3. (a) sigma conocida -> valor critico de la NORMAL
qnorm(0.975)                            # 1,960
IC_z <- xbar + c(-1,1) * qnorm(.975) * EE; IC_z      # 20,41 a 24,39

# Paso 4 y 5. (b) sigma desconocida -> t de Student con n-1 grados
gl <- n - 1; gl
qt(0.975, gl)                           # 2,015
IC_t <- xbar + c(-1,1) * qt(.975, gl) * EE; IC_t     # 20,36 a 24,44

# Paso 6 y 7. (c) subir la confianza al 99 % aleja el valor critico
qt(0.995, gl)                           # 2,692
IC_99 <- xbar + c(-1,1) * qt(.995, gl) * EE; IC_99   # 19,67 a 25,13

# Paso 8. Con 44 grados de libertad, t y z casi coinciden
c(ancho_z = diff(IC_z), ancho_t = diff(IC_t))
# Con n pequeno la diferencia si seria grande:
qt(.975, 4); qt(.975, 44); qt(.975, 500); qnorm(.975)

# Paso 9. El intercambio de fondo: mas confianza se paga con menos precision
c(ancho_95 = diff(IC_t), ancho_99 = diff(IC_99))
diff(IC_99) / diff(IC_t) - 1            # 34 % mas ancho

# Regla practica: con sigma desconocida, usar SIEMPRE la t.
# Con n grande converge a la z, asi que nunca es un error.

# ---------------------------------------------------------------------
# Atajo: t.test() sobre los datos entrega el intervalo directamente
# ---------------------------------------------------------------------
set.seed(3); datos <- rnorm(n, xbar, s)
t.test(datos)$conf.int
t.test(datos, conf.level = 0.99)$conf.int

# ---------------------------------------------------------------------
# Representacion grafica: los tres intervalos comparados
# ---------------------------------------------------------------------
ics <- rbind("z 95 %" = IC_z, "t 95 %" = IC_t, "t 99 %" = IC_99)
plot(NULL, xlim = c(19, 26), ylim = c(0.5, 3.5), yaxt = "n", ylab = "",
     xlab = "puntaje", main = "Mismos datos, tres intervalos")
axis(2, at = 3:1, labels = rownames(ics), las = 1, cex.axis = .8)

Programa oficial UNAB · Intervalos de confianza

Intervalo para una proporción

Para estimar la prevalencia de una característica, el intervalo se construye alrededor de la proporción muestral p.

p ± Z · √[ p(1 − p) / n ]
Ejemplo

En 140 asmáticos, el 35 % tenía alergia al polvo doméstico. El IC del 95 % para esa proporción se calcula con la fórmula anterior y comunica la precisión de ese 35 %.

Ejercicio resuelto · Clase 9

Intervalo de confianza para una proporción

Dificultad media
En una encuesta a 140 pacientes asmáticos, el 35 % declara alergia al polvo doméstico. Construya el intervalo de confianza al 95 % para la proporción poblacional.
  1. Anotar los datos y verificar la condición de aproximación normal: se requiere np ≥ 5 y n(1−p) ≥ 5.
    n = 140 · p̂ = 0,35 → np̂ = 49 y n(1−p̂) = 91 ✓
  2. Escribir el error estándar de una proporción, que depende de la propia proporción estimada.
    EE = √[p̂(1 − p̂) / n]
  3. Calcular el producto del numerador.
    0,35 × 0,65 = 0,2275
  4. Completar el error estándar.
    EE = √(0,2275 / 140) = √0,001625 = 0,0403
  5. Aplicar el valor crítico del 95 %.
    d = 1,96 × 0,0403 = 0,079
  6. Construir el intervalo.
    IC₉₅ = 0,35 ± 0,079 → [0,271 ; 0,429] o 27,1 % a 42,9 %
  7. Interpretar en términos útiles para el servicio: la estimación tiene un margen de casi 8 puntos porcentuales, lo que puede ser demasiado impreciso para planificar recursos.
  8. Calcular qué n haría falta para reducir el margen a 3 puntos porcentuales.
    n = 1,96² × 0,2275 / 0,03² = 0,8740 / 0,0009 = 971 pacientes
IC₉₅ = [27,1 % ; 42,9 %]. Para bajar el margen de 8 a 3 puntos porcentuales haría falta pasar de 140 a 971 pacientes.
Cómo se vería la representación

El intervalo no llega al 50 %, la línea roja: se puede afirmar que es menos de la mitad.

# =====================================================================
# Clase 9 - Intervalo de confianza para una proporcion
# =====================================================================
n <- 140; x <- 49                    # 35 % de 140 asmaticos
p <- x / n; p                        # 0,35

# Paso 1. Condicion de la aproximacion normal: np y n(1-p) al menos 5
c(n*p, n*(1-p))                      # 49 y 91, holgado

# Paso 2 a 4. Error estandar de una proporcion

Programa oficial UNAB · Muestreo

Universo, población, marco y unidad de muestreo

Universo o población diana

Totalidad de individuos en los que puede presentarse la característica de interés. Se define por criterios de persona, lugar y tiempo, no por conveniencia.

Población accesible

La parte del universo a la que el equipo investigador realmente puede llegar.

Marco de muestreo

Listado operativo que identifica cada una de las unidades de muestreo. Sin marco no hay muestreo probabilístico.

Unidad de muestreo

Cada elemento que compone el marco. Puede no coincidir con la unidad de observación: se muestrean colegios y se observan estudiantes.

Error de muestreo

Diferencia entre el valor de la muestra y el de la población, atribuible al azar de la selección. Disminuye al aumentar n y es cuantificable.

Error ajeno al muestreo

Errores de medición, no respuesta, marco incompleto. No disminuye al aumentar n y no se corrige con estadística.

Aumentar el tamaño de la muestra reduce el error de muestreo y puede incluso amplificar el error ajeno al muestreo, porque produce estimaciones precisas de una cifra sesgada.

Los cuatro diseños probabilísticos

Aleatorio simple

Cada unidad tiene la misma probabilidad de ser seleccionada y todas las muestras de tamaño n son igualmente probables. Exige marco completo.

Sistemático

Se selecciona una de cada k unidades, con k = N/n y arranque aleatorio entre 1 y k. Sencillo en terreno; falla si el marco tiene periodicidad.

Estratificado

Se divide la población en estratos homogéneos y se muestrea dentro de cada uno. Garantiza representación de grupos minoritarios y reduce la varianza.

Por conglomerados

Se seleccionan grupos completos (consultorios, cursos, manzanas). Abarata el terreno y aumenta la varianza, porque los miembros de un conglomerado se parecen entre sí.

En los diseños no probabilísticos (por conveniencia, por cuotas, bola de nieve) no se puede calcular el error de muestreo ni construir intervalos de confianza válidos.

# Paso 3. Arranque aleatorio entre 1 y k, y luego cada k-esimo

# Paso 8 a 10. Con el estratificado, la estimacion global es un
# PROMEDIO PONDERADO de los estratos, no un promedio simple.
# prev_global <- sum(pesos * prev_por_estrato)

# ---------------------------------------------------------------------

# ---------------------------------------------------------------------

  ids <- if (tipo == "est") unlist(lapply(names(cupos), function(g)
            sample(marco$id[marco$edad==g], cupos[[g]])))

Las cuatro fórmulas de tamaño muestral

Estimar una media
n = (Zα/2 · σ / d)²

d es el error máximo admisible en las unidades de la variable.

Estimar una proporción
n = Z²α/2 · p(1 − p) / d²

Si p es desconocida se usa p = 0,5, que maximiza n.

Comparar dos proporciones
n = [Zα√(2p̄q̄) + Zβ√(p₁q₁ + p₂q₂)]² / (p₁ − p₂)²
Comparar dos medias
n = 2σ²(Zα + Zβ)² / (μ₁ − μ₂)²
Ajuste por pérdidas
najustado = n / (1 − proporción de pérdidas)

Valores habituales: Zα/2 = 1,96 para 95 % de confianza · Zβ = 0,84 para 80 % de potencia · Zβ = 1,28 para 90 %.

Ejercicio resuelto · Clase 9

Calcular el tamaño muestral para estimar

Dificultad media
Un servicio de neonatología quiere estimar (a) el peso medio de nacimiento con un error máximo de 100 gramos y 95 % de confianza, sabiendo por registros previos que σ ≈ 500 gramos; y (b) la prevalencia de un factor de riesgo con un error máximo de 5 puntos porcentuales y 95 % de confianza, sin información previa sobre su magnitud.
  1. Para (a), escribir la fórmula del tamaño muestral para estimar una media.
    n = (Zα/2 · σ / d)²
  2. Identificar cada componente en el enunciado.
    Z = 1,96 · σ = 500 g · d = 100 g
  3. Sustituir y resolver el paréntesis.
    1,96 × 500 / 100 = 980 / 100 = 9,8
  4. Elevar al cuadrado y redondear siempre hacia arriba, porque no existen fracciones de paciente.
    n = 9,8² = 96,04 → 97 recién nacidos
  5. Para (b), escribir la fórmula para estimar una proporción.
    n = Z² · p(1 − p) / d²
  6. Resolver el problema de no conocer p: se adopta el valor más desfavorable, que maximiza el producto p(1 − p).
    p = 0,50 → p(1 − p) = 0,25 (el máximo posible)
  7. Sustituir los valores.
    n = 1,96² × 0,25 / 0,05² = 3,8416 × 0,25 / 0,0025
  8. Completar el cálculo y redondear hacia arriba.
    n = 0,9604 / 0,0025 = 384,2 → 385 personas
  9. Comprobar el costo de la precisión: reducir el error de 5 a 2,5 puntos porcentuales cuadruplica la muestra, porque d aparece al cuadrado.
    n = 0,9604 / 0,000625 = 1 537 personas
(a) 97 recién nacidos · (b) 385 personas. Duplicar la precisión exige cuadruplicar la muestra.

Usar p = 0,5 cuando no hay información previa es la decisión conservadora: garantiza que la muestra nunca quedará corta.

Tamaño muestral para comparar dos grupos, con ajuste por pérdidas

Dificultad alta
Se planifica un ensayo clínico que compara un tratamiento estándar, con eficacia conocida del 60 %, frente a uno nuevo del que se espera un 85 %. Se desea un nivel de significación del 5 % y una potencia del 80 %. Se anticipa una pérdida de seguimiento del 15 %. ¿Cuántos pacientes hay que reclutar por grupo?
  1. Anotar los parámetros del diseño y traducir significación y potencia a valores Z.
    p₁ = 0,60 · p₂ = 0,85 · Zα = 1,96 · Zβ = 0,84
  2. Calcular la proporción promedio, que se usa bajo el supuesto de la hipótesis nula.
    p̄ = (0,60 + 0,85)/2 = 0,725 → q̄ = 0,275
  3. Calcular el primer término del numerador.
    √(2 × 0,725 × 0,275) = √0,39875 = 0,6315 → 1,96 × 0,6315 = 1,238
  4. Calcular el segundo término, que corresponde a la varianza bajo la hipótesis alternativa.
    p₁q₁ = 0,240 · p₂q₂ = 0,1275 → √0,3675 = 0,6062 → 0,84 × 0,6062 = 0,509
  5. Sumar ambos términos y elevar al cuadrado.
    (1,238 + 0,509)² = 1,747² = 3,052
  6. Dividir por el cuadrado de la diferencia que se quiere detectar.
    (p₁ − p₂)² = 0,25² = 0,0625 → n = 3,052 / 0,0625 = 48,8 → 49 por grupo
  7. Aplicar el ajuste por pérdidas de seguimiento sobre el resultado.
    n_ajustado = 49 / (1 − 0,15) = 49 / 0,85 = 57,6 → 58 por grupo
  8. Totalizar el reclutamiento del ensayo.
    58 × 2 = 116 pacientes
  9. Examinar la sensibilidad del cálculo: si la diferencia esperada fuese de 10 puntos en vez de 25, el denominador cae a 0,01 y el tamaño se multiplica por más de seis.
    Diferencias pequeñas exigen muestras muy grandes
  10. Cerrar con la advertencia ética y metodológica: un estudio con potencia insuficiente expone pacientes a un riesgo sin poder responder la pregunta. Calcular el tamaño muestral no es un trámite administrativo.
49 pacientes por grupo por cálculo, 58 tras el ajuste por 15 % de pérdidas, es decir 116 pacientes en total.

}

El Censo de 2012 quedó marcado por problemas de cobertura y de calidad de los datos, y terminó cuestionado y repetido en 2017.

Un censo intenta medir a toda la población, sin muestreo. Cuando el operativo falla (viviendas no visitadas, registros incompletos), ni siquiera "medir a todos" garantiza un buen dato: la calidad del diseño y la ejecución importan tanto como el tamaño.

Cierre de la sesión · ideas fuerza

Qué debería quedar de esta clase

Ideas para salir con ellas
  • Una estimación puntual sin su incertidumbre es información incompleta. El intervalo de confianza es el que dice cuánto se puede afinar la conclusión.
  • La confianza es una propiedad del procedimiento, no del intervalo concreto que se calculó. El 95 % describe cuántos de los intervalos así construidos contendrían el parámetro.
  • El ancho del intervalo depende de tres cosas: la variabilidad del dato, el tamaño de muestra y el nivel de confianza. Solo la segunda está bajo control de quien diseña el estudio.
  • El diseño de muestreo decide a quién representan los resultados, y el error ajeno al muestreo no se reduce agrandando la muestra.
  • El tamaño muestral se calcula antes de recoger los datos, a partir de la precisión que se quiere, y se ajusta por las pérdidas de seguimiento esperadas.
Lo que viene
  • La Unidad IV continúa con las pruebas de hipótesis y el valor p.
  • El intervalo de confianza de hoy y el contraste de la próxima clase son dos formas de mirar la misma información.
  • Conviene tener claro qué es el error estándar: reaparece en el denominador de todos los estadísticos de contraste.

Antes de creer una cifra de un estudio, la pregunta es de qué tamaño era la muestra y cómo se eligió.
